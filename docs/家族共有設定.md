# あぜみち 家族間データ共有（世帯）の設定手順

ログイン版の記帳（/app/kicho）・農薬肥料記録（/app/boujo）・農作業日誌（/app/nisshi）のデータを、家族で共有できる機能です。同じ「世帯」のメンバーは全員、記録の閲覧・追加・編集・削除ができます。

書類作成ツールや無料版（/kicho・/boujo・/nisshi 等）には影響しません。

---

## 1. Supabaseにテーブル・関数を作る（SQL Editorで1回だけ実行）

1. Supabaseの画面で「SQL Editor」を開く
2. `docs/household-sharing-setup.sql` の中身を全部コピーして貼り付け、実行する
3. これで「世帯」の仕組みができます
   - 既存の全ユーザーには「自分だけの世帯」が自動で作られ、**今ある記録はそのまま各自の世帯に入ります**（データは失われません）
   - 以降、新規登録した人にも自動で「自分だけの世帯」ができます

環境変数の追加設定は不要です（ログイン機能ですでに設定済みのものを使います）。

## 2. 使い方

### 招待する側
1. ログインして、画面上部の「共有設定」（`/app/settings`）を開く
2. 招待したい家族のメールアドレスを入力して「招待リンクを作る」
3. できた**招待リンク**を、LINEやメールで相手に送る

### 招待される側
1. 先に `/login` で、招待に使われたメールアドレスで**新規登録・ログイン**する
2. 送られてきた**招待リンク**を開く
3. 「招待を承認して共有を始める」を押す → 共有開始

承認すると、承認した人がそれまで持っていた記録も、共有先の世帯に引き継がれます。

## 3. メンバーを外す

- `/app/settings` の「世帯のメンバー」で、**ホスト**（世帯を作った人）は他のメンバーを「外す」ことができます
- 外された人の**記録は世帯（ホスト側）に残ります**。外された人は、記録が空の新しい世帯からやり直します
- ホスト自身は世帯から抜けられません（世帯の解散・ホストの譲渡は今後対応予定です）
- ホスト以外のメンバーは、自分でこの世帯から抜けることもできます

---

## 仕組み（技術メモ）

- 「世帯（households）」を作り、`kicho_entries`・`boujo_entries`・`nisshi_entries` を `household_id` に紐づけました（`user_id`＝記録した本人、も残しています）
- RLS（行レベルセキュリティ）は「同じ世帯のメンバーだけ読み書きできる」に張り替え済み。他の世帯のデータは一切見えません
- 招待の承認・メンバーの除外は、サーバー側の関数（`accept_invitation`・`remove_member`）で安全に処理します
- 招待メールの自動送信はしません（招待リンクを手動で送る簡易版）。承認できるのは、招待で指定したメールアドレスのアカウントだけです
